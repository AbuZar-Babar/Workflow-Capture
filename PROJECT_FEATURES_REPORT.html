Executive Summary & Problem Statement

Conventional robotic process automation (RPA) and record-and-replay tools suffer from three severe bottlenecks: (1) Credential Loss & 2FA Failure (launching blank browsers that cannot bypass modern enterprise SSO or MFA), (2) Selector Fragility (breaking when framework-generated IDs or dynamic layouts mutate), and (3) Inability to Scale Beyond a Single Demonstrated Action.

Workflow Capture solves this by attaching directly to the user's running, authenticated Google Chrome instance, computing resilient multi-factor selector fingerprints, and applying an intelligent Item Discovery and Action Generalizer engine. An operator demonstrates how to download one invoice; the system automatically locates all equivalent records on the page, generalizes the procedure, isolates item errors, and produces an auditable run manifest with downloaded artifacts.

End-to-End Execution Pipeline

Deterministic Design

The system workflow operates deterministically from user demonstration to batch artifact collection without requiring cloud credentials or complex machine learning models at the core execution layer:

Step 1 • Capture Human Demonstration Operator records a single invoice download in live Chrome via CDP.
Step 2 • Fingerprint Selector Resolver Calculates multi-candidate selectors and strips transient framework noise.
Step 3 • Discover Item Discovery Detects repeated table rows/cards and presents count & confidence for confirmation.
Step 4 • Generalize Action Generalizer Converts row-specific CSS into item-scoped (:scope) relative targets.
Step 5 • Kinematics Human Stealth Evasion Applies Bézier curve trajectories and typing hesitation cadences.
Step 6 • Isolation Loop Execution Engine Processes each item sequentially. Failed items are isolated without crashing the run.
Step 7 • Storage Artifact Interceptor Catches downloaded PDFs/CSVs and groups them per item in run directories.
Step 8 • Audit Run Manifest & Monitor Emits structured JSON manifest ready for future Document AI pipelines.

Module 3 — Isomorphic Weighted Selector Resolver

src/shared/selector-resolver.js

A single, isomorphic JavaScript engine running identically in the browser during recording and during replay. Generates ranked candidate selectors and applies weighted fingerprint matching when DOM structures shift.

Dynamic ID & Class Filtering

Anti-Noise Heuristics
🛡️

Enterprise frameworks generate volatile IDs (e.g. Angular mat-input-0, ExtJS ext-gen1042, React :r1:) that change every render.

  • Identifies and purges randomized numeric and framework hash suffixes.
  • Filters transient UI state classes (active, hover, mat-focused, ng-dirty).
  • Protects against brittle element lookup during replay.
Test: selector-resolver.test.js Passing (8/8)

Multi-Factor Fingerprint Scoring

Weighted Match Resolution
⚖️

When strict CSS selectors fail due to layout updates, the resolver evaluates candidate elements using multi-factor fingerprint weights:

  • Tag Name Match: Mandatory baseline (failure yields 0 score).
  • Stable ID & Data Attributes: Weighted at 30% contribution.
  • ARIA Role & Semantic Labels: Weighted at 25% contribution.
  • Tokenized Text Overlap (Jaccard): Resilient against Angular template whitespace variations.
Confidence Threshold: ≥ 0.70 Verified

Angular Material MDC Resiliency

Complex Component Handling
⚡

Handles complex multi-layer web components natively:

  • Composite Control Mapping: Interacts with the parent host rather than internal non-clickable pseudo-checkboxes.
  • Backdrop Dismissal: Discovers transparent CDK overlay backdrops to close open dropdown menus cleanly.
  • Idempotent Comboboxes: Checks aria-expanded before clicking to prevent accidental toggling.

Module 5 — Scoped Action Generalizer (:scope)

src/shared/action-generalizer.js

Replaces rigid, absolute document selectors with item-relative selectors so the same recorded action can run against item #1, item #2, ..., item #N.

// Original Absolute Selector Captured on Invoice Row #1: const raw = "#invoices-table > tbody > tr:nth-of-type(1) > td:nth-of-type(5) > a.download"; // Action Generalizer Transformation into Scoped Element Selector: const scoped = generalizeSelector(raw, itemRow); // Result: ":scope > td:nth-of-type(5) > a.download"

Relative Path Scoping

DOM Element Anchoring
✂️

Detects the item element boundary inside the selector chain and strips prefix hierarchies, converting nth-child paths to standard :scope expressions.

  • Re-queries the DOM dynamically for each item row during iteration.
  • Handles the item itself as :scope if the recorded action was clicking the row.
  • Gracefully retains non-item fixed actions (e.g. top-level search, initial filter).
Test: action-generalizer.test.js Passing (5/5)

Multi-Action Loop Partitioning

Multi-Step Procedures
🪜

Supports complex, multi-action workflows per item rather than just single clicks:

  • Allows sequences like: Expand Row → Click Download → Close Preview Modal.
  • Partitions the workflow into Fixed Pre-Actions, Loop Actions, and Post-Actions.
  • Executes the entire multi-step sequence cleanly for each item.

Module 6 — Fault-Tolerant Loop & Artifact Tracking

src/replay/loop-replay-runner.js

A resilient batch runner designed specifically for long document-collection jobs where individual network hiccups or corrupt rows must not kill the batch.

Per-Item Error Isolation

Zero-Crash Fault Boundary
🛡️

Every item runs inside an isolated try/catch transaction boundary.

  • If Invoice #3 fails (missing button, 500 error), it is marked FAILED with exact diagnostic error.
  • The engine automatically performs state recovery (closes open dialogs, returns to table view).
  • Immediately proceeds to Invoice #4 without interrupting the broader execution run.
Result: Safe, autonomous overnight runs Verified

Atomic Checkpoint & Resume

Crash Recovery State
💾

Saves progress after every processed record to local disk:

  • Records completed indices, download hashes, and per-item statuses.
  • If browser or server is shut down, execution can resume directly from the first unprocessed item.
  • Eliminates duplicate downloads and wasted API calls.
Storage: data/db.json / runs collection Verified

CDP Download Interception

Run Manifest Generation
📥

Intercepts native browser file download events via Chrome CDP:

  • Validates that the file has actually finished downloading to disk (not just that a link was clicked).
  • Associates the downloaded file directly with the corresponding item identity.
  • Organizes files under recordings/runs/{runId}/ and emits a machine-readable manifest.json.

Module 7 — Human Mouse Kinematics & Stealth Evasion

src/replay/human-mouse.js

Anti-bot detection software analyzes pointer movement linearity and keystroke intervals. Workflow Capture implements biological kinematic algorithms to evade bot classification.

Cubic Bézier Mouse Curves

Non-Linear Trajectories
〰️

Constructs smooth cubic Bézier splines between mouse coordinates rather than teleporting or moving in straight robotic lines.

  • Calculates control points using randomized perpendicular offsets.
  • Simulates acceleration and deceleration with micro-overshoot and target settling corrections.
  • Passes behavioral mouse biometric analyses (Cloudflare Turnstile, DataDome).
Test: bot-config.test.js Passing (4/4)

Stochastic Typing Cadence

Human Typing Hesitation
⌨️

Emulates natural keyboard interaction dynamics:

  • Gaussian distribution of inter-character delays (50ms - 180ms).
  • Hesitation delays upon reaching punctuation marks (., ,, @).
  • Four configurable speed presets: stealth, balanced, fast, and instant.
